# Roadmap — CLP Fácil

## Fase 0 — Base do projeto

- Criar repositório separado.
- Documentar visão, MVP, arquitetura e catálogo de lições.
- Definir tecnologia inicial.
- Preparar prompt de implementação.

## Fase 1 — App educativo mínimo

- Criar app Android-first com React Native e Expo.
- Implementar navegação básica.
- Criar tema escuro profissional.
- Criar tela inicial com módulos.
- Criar primeira lição funcional.

Entregas:

- HomeScreen.
- ModuleScreen.
- LessonScreen.
- SimulatorScreen.
- Componentes visuais básicos.
- Engine inicial para partida direta com selo.

## Fase 2 — Módulo Fundamentos

Lições:

- Contato NA.
- Contato NF.
- Bobina.
- AND.
- OR.
- Selo.
- Intertravamento.

## Fase 3 — Módulo Motores

Lições:

- Partida direta simples.
- Partida direta com selo.
- Emergência.
- Sobrecarga.
- Reversão de motor.
- Partida sequencial.

## Fase 4 — Temporizadores e contadores

Lições:

- TON.
- TOF.
- Pulso.
- CTU.
- Reset.
- Contagem de peças.

## Fase 5 — Desafios

- Desafios prontos.
- Validação automática simples.
- Feedback de erro.
- Progresso por nível.

## Fase 6 — Monetização

- Banner discreto.
- Compra Pro vitalícia.
- Remover anúncios.
- Liberar lições avançadas.
- Progresso completo.

## Fase 7 — Editor Ladder simples

- Editor por blocos.
- Entradas I.
- Saídas Q.
- Memórias M.
- Temporizadores T.
- Contadores C.
- Simulação segura e educativa.

## Fase 8 — Modo educador

- Pacotes de exercícios.
- Compartilhamento de desafios.
- Relatório de desempenho.

## Prioridade atual

A prioridade imediata é a Fase 1:

- app abre;
- visual é coerente;
- primeira lição simula corretamente;
- base técnica está limpa;
- o projeto fica pronto para testes e publicação futura.
