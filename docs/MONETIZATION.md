# Monetização — CLP Fácil

## Princípio

A monetização deve ser leve e não pode atrapalhar o aprendizado. O usuário deve conseguir testar o valor real do app antes de pagar.

## Versão gratuita

A versão gratuita deve conter:

- lições básicas de fundamentos;
- parte inicial do módulo de motores;
- anúncios discretos;
- progresso local simples;
- acesso sem login.

## Versão Pro

A versão Pro pode liberar:

- remoção de anúncios;
- módulos avançados;
- desafios extras;
- temporizadores e contadores completos;
- exportação futura de imagem/PDF;
- temas extras;
- progresso completo.

## Modelo recomendado

No início, priorizar compra vitalícia simples em vez de assinatura.

Motivos:

- reduz resistência de estudantes;
- combina com app educativo;
- facilita divulgação;
- evita pressão de entregar serviço recorrente antes da hora.

## Anúncios

Usar apenas formatos pouco invasivos:

- banner pequeno em telas de listagem;
- anúncio recompensado apenas se fizer sentido no futuro;
- evitar intersticial agressivo durante simulações.

## Cuidados

- Não colocar anúncio entre o usuário e o aprendizado principal.
- Não bloquear lições essenciais para o app parecer vazio.
- Não usar permissões desnecessárias.
- Não exigir cadastro no MVP.

## Funil futuro

O CLP Fácil pode gerar autoridade para outros produtos técnicos, mas deve se manter como app próprio e útil por si só.
